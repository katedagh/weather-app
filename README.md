# Weather Forecast App

A simple weather forecast application built with HTML, CSS and JavaScript.
[Live Demo](https://katedagh.github.io/weather-app/)


## About the project

This project was created as a practice project to improve my JavaScript skills and learn how to work with external APIs.
The application allows users to search for a city and view its current weather conditions and hourly forecast.


## Features

- Search for a city by name
- Retrieve geographical coordinates using a geocoding API
- Display current weather information
- Show hourly weather forecast
- Day and night weather icons
- Dynamic weather descriptions
- Error handling for invalid city names


## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Open-Meteo API


## While building this project, I practiced:

- Working with asynchronous JavaScript (async/await)
- Fetching data from external APIs
- Processing JSON responses
- DOM manipulation
- Event handling
- Handling missing API results and invalid user input
